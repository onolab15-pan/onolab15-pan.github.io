How to play & image settings

Choose a mode and type using English letters. Correct answers are recognized automatically. Read the answer, then select “Next” (or press Enter). Changing modes or selecting “Restart” resets your plate count. You can still earn a plate when using a hint.

Romaji accepts shi / si, chi / ti, tsu / tu, ji / zi, cha / tya, and other common spellings. For small っ, double the consonant or use xtu / ltu. For ん, use n / nn / n' (before a vowel or y sound, use nn / n'). For ー, repeat the vowel or use - (for example, saamon / sa-mon). English answers are case-insensitive; spaces and hyphens are treated the same.

This game shares the 40 photos used by Sushi Word Cards. To use other photos without text, set their path below. {id} is replaced with 01–40. Example: ../sushi-words/images/sushi-{id}.jpg. Only the current question’s photo is loaded. This setting lasts until you close the page.

If a photo is unavailable, a generic illustration and a hint are shown. The illustration does not depict the specific sushi variety.
